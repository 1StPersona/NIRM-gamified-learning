# Задание 2. Рецензия на черновик

**Рецензия на статью «Elo-Based Adaptive Gamification for Programming Practice» (версия 1)**

**Краткое содержание.** Авторы предлагают модель адаптивной геймификации для практики программирования: рейтинг Эло оценивает способность студента и сложность задачи, следующая задача выбирается с прогнозом успеха около 0,7, опыт зависит от сложности. На симуляции из 1 500 студентов адаптивный выбор удерживает задачи в «зоне посильной сложности» в 79 % попыток против 40 % у линейного порядка. Рейтинг Эло прогнозирует успех немного точнее статических меток. Описан протокол эксперимента.

**Сильные стороны.**

1. Проблема поставлена ясно и обоснована противоречивыми результатами из литературы, а не общей фразой «тема мало изучена».
2. Результаты сообщаются с доверительными интервалами и размерами эффекта; авторы прямо пишут, что p-значения в симуляции малоинформативны.
3. Честно описан отрицательный результат (холодный старт у сильных студентов) и показано, откуда он берётся (разбивка по четвертям попыток).
4. Код и данные открыты, результаты воспроизводятся двумя командами.

**Слабые стороны и замечания.**

*Существенные:*

- **З1. Замкнутость симуляции.** Синтетические студенты отвечают по той же логистической модели, на которой построен рейтинг Эло. Это заведомо выгодно для Эло. Нужна хотя бы одна проверка на модели, которая отличается от модели системы (угадывание, ошибки по невнимательности, рост способности во время курса). Без неё выводы по RQ3 не убедительны.
- **З2. Средство от холодного старта предложено, но не проверено.** Раздел «Обсуждение» называет две меры, но ни одна не оценена, хотя симуляция для этого готова. Это ослабляет ответ на RQ2.
- **З3. Произвольность главной метрики.** Границы «зоны посильной сложности» 0,5–0,85 не обоснованы. Нужно показать, что вывод не зависит от выбора границ.

*Незначительные:*

- **З4.** Базовая модель для RQ3 слабая: метка сложности — округлённая до целого истинная сложность. Стоит назвать это ограничение явно.
- **З5.** Протокол эксперимента описан кратко; неясно, зарегистрирован ли он уже.
- **З6.** На рисунке 1 подписи по оси X наезжают друг на друга, легенда обрезана.

**Рекомендация:** незначительная доработка (minor revision) при условии, что замечания З1 и З2 будут закрыты дополнительными прогонами симуляции. Тема соответствует площадке, вклад скромный, но работа методически аккуратна и полезна как основа для эксперимента.
