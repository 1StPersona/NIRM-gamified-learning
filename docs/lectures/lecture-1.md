## Лекция 1. Исследовательский проект

### 1.1. Тема проекта

Разработка и экспериментальная оценка адаптивной модели геймификации для платформы обучения программированию, в которой сложность заданий-квестов подбирается по рейтингу Эло студента, а игровые награды (опыт, уровни, значки, серии) начисляются по формализованным правилам. Работа проверяет, повышает ли такая модель вовлечённость и результативность студентов IT-направлений по сравнению со статической геймификацией и с обычной системой автопроверки кода.

Это именно исследование, а не инженерная разработка: платформа (FastAPI-микросервисы, React, RabbitMQ) — инструмент, а вклад — модель и ответ на вопрос о её эффекте.

### 1.2. Исследовательский вопрос

По формуле лекции «объект → метод → сравнение → метрика»:

> **RQ.** Повышает ли адаптивная геймификация (подбор сложности по рейтингу Эло с целевой вероятностью успеха ≈ 0,7 + XP, уровни, значки) индекс вовлечённости и долю решённых задач студентов, изучающих программирование, по сравнению со статической геймификацией и с платформой без игровых элементов?

| Элемент RQ | В диссертации |
| --- | --- |
| Объект | студенты IT-направлений, решающие задачи по программированию на платформе |
| Метод | адаптивная модель геймификации из главы 2 (формулы 2.6–2.12) |
| Сравнение | статическая геймификация; платформа без игрового слоя |
| Метрика | индекс вовлечённости (формула 2.5), доля решённых задач |

### 1.3. Значимость и научный вклад (≈ 180 слов)

На первых курсах программирования студенты часто теряют мотивацию: задачи оказываются либо слишком лёгкими, либо непосильными, а системы автопроверки выдают только вердикт «принято / не принято». Геймификация широко применяется как ответ на эту проблему, однако мета-анализы показывают небольшие и неустойчивые эффекты, а большинство платформ начисляет награды по фиксированным правилам, не учитывая уровень подготовки студента. Адаптивные системы, напротив, подбирают сложность, но редко используют игровой слой и почти не встречаются в системах автопроверки кода. Работа объединяет эти два направления. Научный вклад состоит из трёх частей. Во-первых, новая метрика: сводный индекс вовлечённости, вычисляемый из журнала событий платформы. Во-вторых, новая постановка задачи и модель: замкнутый адаптивный контур, связывающий рейтинг Эло, начисление опыта и выдачу квестов. В-третьих, эмпирические данные контролируемого эксперимента с тремя условиями и открытый обезличенный набор данных. Практическая значимость: готовая платформа может использоваться в курсах программирования Satbayev University.
