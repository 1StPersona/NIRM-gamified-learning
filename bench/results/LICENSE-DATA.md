# Лицензия на данные

Результаты симуляций и бенчмарков в этой папке (`*.csv`, `*.json`, `*.md`, `*.txt`) распространяются по лицензии
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Можно копировать, изменять и использовать в любых целях при условии ссылки на источник (см. `CITATION.cff`).

Все данные синтетические: они получены моделью и не содержат сведений о реальных людях.
Код репозитория распространяется по лицензии Apache 2.0 (`LICENSE`).
